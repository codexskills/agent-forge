# Architecture Blueprint Skill

Forces architecture-first workflow before any implementation. Acts as a Principal Software Architect.

## Phases

| Phase | What It Does |
|-------|--------------|
| 0 | Feasibility Analysis |
| 1 | Requirements Discovery |
| 2 | Architecture Planning |
| 3 | Specification Generation |
| 4 | Roadmap Planning |
| 5 | Architecture Validation |

## Example

```
User: Build me a food delivery app
Agent: Running architecture-blueprint...

Phase 0: Feasibility — Medium complexity, 2-3 weeks
Phase 1: Requirements — 12 requirements, 3 assumptions found
Phase 2: Architecture — Event-driven microservices + PostgreSQL + Redis
Phase 3: Spec — 15 functional, 8 non-functional requirements
Phase 4: Roadmap — 4 milestones over 6 weeks
Phase 5: Validation — 11/11 checks passed

Ready to implement. Architecture blueprint generated.
```
